# Progress log

What the project found at each step, what changed because of it, and which files show it. Newest first. The oversight chat adds an entry whenever it writes a memo or an instruction, reviews a gate report, or settles a decision, in the same commit as that work. Entries are not rewritten afterwards. A factual error is fixed with a dated correction beside it.

## Round 6 (from 11 October 2026)

**12 October, 02:20. Writers are asked to use their allowance.** The pilot's three writers used 6,890 to 17,690 of their 32,768 bytes, so the size limit was never binding and larger allowances might not have changed anything. With Nicolas's agreement, the writer prompt gained the sentence "Use as much of the allowed size as helps; more detail is generally better," before any C2 writer ran. The final report shows accuracy against both the allowance and the bytes actually written.

**12 October, 02:10. Round 6's grid is cut to Opus alone.** To cut time and cost further, Nicolas decided that C2 runs only Opus 5.5 at medium effort, with one replicate per cell. That is 20 sessions: two baselines, six writers, nine predictors and three combined sessions. Haiku's and Sonnet's high-effort pilot trials stay as reference values at one cell, so the comparison across models rests on that cell alone. With one trial per cell, the final report treats differences of under about 0.05 as within chance. The C1 memo, the instruction and the masterplan carry dated revision lines.

**12 October. C1 gate of the cheatsheet track** (`docs/round06/i02/cheatsheet/round06_cheatsheet_C1_decisions.md`, report `round06_cheatsheet_C1_report.md`, pull request #23). Setup passed every check. The confined trials could reach nothing but the API, and the benchmark head reproduces round 1's SKCM values within 0.000068 (`results/round6/cheatsheet/C0_comparators/anchor.csv`). The session also caught that the stored coordinates were transposed relative to the images and fixed it before any trial used them. In the pilot at high effort, zero-shot Opus scored 0.502 on the held-out spots, above the oversight chat's predicted range of 0.05 to 0.35. With a 32,768-byte cheatsheet from the training region, every model beat its own baseline (0.545, 0.400 and 0.600 for Haiku, Sonnet and Opus). Every model stayed below the `uni_v2` benchmark head fitted on the same 814 spots, at 0.757, and so did Opus with the labels in hand, at 0.705 (`results/round6/cheatsheet/C1_pilot/c1_trials.csv`, `results/round6/cheatsheet/C0_comparators/comparators.csv`). The full grid projected to 48.05 US dollars at API prices, 43.39 of it Opus. Nicolas decided that effort is medium from here, so the pilot becomes a high-effort reference and every grid slot is run afresh. The memo also excludes trials only for signs of a leak, not for refused network attempts, since the pilot's rule had left Haiku's combined slot empty. It adds one sentence to every prompt saying there is no internet access, and runs the full grid in one session at up to four trials at once. The masterplan gained a section explaining scored spots, the codebook and replicates.

**11 October, evening. Round 6's execution moves to a cloud session.** Before any session started, Nicolas asked that the execution session run as a cloud session from the desktop app so that it uses his usage credits, and asked whether the experiment could run in parallel. The oversight chat tested the route in its own cloud container. A headless child Claude Code session authenticated on his account and answered with Haiku, and inside a bubblewrap confinement that showed it only its own folder it could not see a file planted elsewhere in the container. The container's egress refuses HuggingFace and 10x Genomics. A second test ran the full confinement, with its own process and network namespaces and a filtering proxy reached through a Unix socket. For speed, the second interval's grid can be split by model across up to three cloud sessions, each with its own container, which adds compute but shares the account's usage limits. **11 October. Round 6 opens on David's cheatsheet experiment** (`docs/round06/masterplan.md`, instruction `docs/round06/i01/cheatsheet/round06_cheatsheet_track.md`). David proposed by email that an agent predict 50 genes from H&E patches, with and without a size-limited text cheatsheet written by an agent that saw the expression, and asked how large the cheatsheet must be to reach a given accuracy. Nicolas decided to run it as round 6 and set its purpose, which is to learn whether few-shot prediction with a general-purpose language model can beat pathology foundation models, so nothing restricts what a cheatsheet contains. He decided that writer and predictor are always separate fresh sessions, each in its own sandbox, that all three arms run (same slide, held-out region, held-out slide), that a session holding both the labels and the targets is the $b = \infty$ point of each arm rather than a separate design, that the metric is HEST-bench's, and that Haiku, Sonnet and Opus 5.5 are compared at high effort with the other axes kept small. He also asked that Claude Code be used in place of Claude Science unless Science has an obvious advantage. The design uses the SKCM task's two slides, sizes of 4,096, 32,768 and 262,144 bytes with two replicates, and the benchmark head on `uni_v2` and `hoptimus1` fitted on the same labelled spots as the comparator, for 117 sessions in all. An independent check of the two documents found a leak through the arm B overview image, the string "hest" in the trial path, a size grid that stopped below the S1 expression matrix's 194,300 bytes and a buffer that let scored and training patches share pixels, and all four were fixed before commit. The GLMP paper David sent has no expression-prediction experiment, and what carries over from it is fixing the prompts in advance. The PPI paper's next round becomes round 7.

**9 October. The inference track closes** (`docs/round05/i04/ppi/round5_ppi_E5_decisions.md`, report `round5_ppi_final_report.md`, pull request #20). The paper's estimator is defined once in `round5_ppi_estimator_definition.md`, with form C within clusters, the cross-fitted between coefficient, the interval with the cross-fitting term, and the stratified draw for the group difference. In regime B the predictors narrow the slope's interval to 0.706 to 0.847 of the classical width on lung and 0.594 to 0.625 on census, and not on the kidney tasks, 0.982 to 1.009 (`results/round5/ppi/E5_joint/e5_joint_design.csv`). Stage E4b added an interval for balanced selection of the labelled clusters, the classical mean with a residual variance. At 8 labelled clusters it is 0.726 of the simple-random classical width on kidney cancer with `uni_v2` and 0.551 on census by state, narrower than tuning under simple random selection at 0.852 and 0.618 (`results/round5/ppi/E4b_rejective/e4b_rej_width_ratios.csv`). With one balance variable and 8 or more labelled clusters it covers within 0.03 of the classical interval, and it fails with two balance variables at few residual degrees of freedom. Its null control failed in two census designs at 4 labelled clusters for a reason not established, so it enters the paper as a design result with conditions and not as the default. The allocation result uses the formula with the measured between ratio. The first question for a next round is weighting the labelled clusters by their inclusion probabilities under rejective selection.

**9 October. The prediction-set track closes** (`docs/round05/i03/conformal/round5_conformal_W5_decisions.md`, report `round5_conf_final_report.md`, pull requests #18 and #19). On real data at 10 calibration donors and 90%, HCP with no labelled target spots is the narrowest valid method up to 5 labelled spots. From 9 labelled spots the full conformal set inside the target donor (`within_full`) is 0.416 to 0.677 of HCP's width and replaces round 4's recommendation of the plain split and the half split. On kidney cancer, GHCP at 5 labelled spots becomes narrower than HCP from 12 calibration donors, reaching 0.831 of HCP's width at 20, and holding the prediction head fixed shows that the number of calibration donors produces this. In GHCP's own simulation designs the full conformal set is 2 to 4 times narrower than GHCP from 9 labelled units wherever GHCP is finite. The released GHCP code calibrates HCP on half of the reference groups, so its 20-group design corresponds to 10 calibration clusters, which puts the paper's designs and the real-data map on one axis. On the theory side, two parts of the small-$K$ proposition are direct corollaries of Tibshirani, Barber and Ramdas, HCP is not pointwise dominated in the revealed-law model, and whether it is dominated in expected width is left open. The memo corrects a row count in the report (1,694,142 matched rows, not 1,693,662) and an error in the W2 memo ("3 to 4 times" should read 2 to 4 times).

**9 October. E4 gate of the inference track** (`docs/round05/i03/ppi/round5_ppi_E4_decisions.md`, report `round5_ppi_E4_report.md`, pull request #17). Three things changed the paper's method.
- The design-target interval gains the cross-fitting term that the finite-population factor had removed. In simulation at 15 clusters and 12 labelled, the ratio of estimated to empirical variance goes from 0.69 to 0.91 without it to 0.97 to 1.01 with it. The paper's interval is `textbook_t|fpc|lin|xf` (`results/round5/ppi/E3a_crossfit/e3a_sim_prediction_cells.csv`).
- Form C, which gives each cluster its own intercept, becomes the paper's within-cluster estimator. A predictor constant within a cluster changes nothing under it. For the slope its classical interval is 4 to 18% narrower than the pooled-intercept form's (`results/round5/ppi/E3_twolevel/e3_prediction_cells.csv`).
- Drawing the group difference stratified by group inside each cluster repairs E2's under-coverage. It covers 0.885 to 0.913 at 6 or more labelled units per donor.

Balanced selection of the labelled clusters cuts the classical estimator's variance (to 0.604 of its value on kidney cancer for `uni_v2` and 0.264 on census by state, at 8 labelled clusters), but no interval run so far shows the gain. The memo adds E4b, an interval built on the classical mean with a residual variance, before the closing stage E5. Two errors were the oversight chat's. Its E2 memo misread three provenance records, and its band for the permuted-balance check assumed the genes gave independent replicates when every gene shares the same draws.

**8 October. W2 gate of the prediction-set track** (`docs/round05/i02/conformal/round5_conformal_W2_decisions.md`, report `round5_conf_W2_report.md`, pull request #16). The simulation map was completed. The full conformal set inside the target cluster (`within_full`) is the narrowest method in 1,350 of 1,440 cells at a between-cluster share of 0.3 and in all 1,440 at 0.9 (`results/round5/conformal/W1_sim/w1_whole_grid_counts.csv`). In GHCP's fixed design with 20 groups, the released GHCP is 27.55 wide at 5 labelled units against 33.40 for HCP (`W2_ghcp_settings/w2_sim_designs.csv`). The memo also set the code-delivery rules both tracks now follow, which are one push per gate, commits delivered to Longleaf as bundles, and jobs run from read-only snapshots.

**8 October. E2 gate of the inference track** (`docs/round05/i02/ppi/round5_ppi_E2_decisions.md`, report `round5_ppi_E2_report.md`, pull request #15). Three findings.
- In regime B (a few labelled units on every cluster) the round-4 classical comparator had no intercept, so a constant predictor appeared to help. Against a constant predictor, the encoders' width is 0.98 to 1.04 on the three kidney tasks, 0.74 to 0.84 on lung and 0.60 to 0.64 on census income (`results/round5/ppi/E2_regimeB/e2_decomposition.csv`). The constant predictor became the primary control.
- Simple random draws inside a donor miss rare groups, and the group difference then under-covers, down to 0.23 on lung at two units per donor (`e2_regimeB_grid.csv`).
- The tuned interval loses coverage when most clusters are labelled, 0.840 at 15 clusters and 12 labelled, because the cross-fitting term escapes the finite-population factor (`results/round5/ppi/E1_interval/e1_sim_grid.csv`).

Each finding produced a stage of interval 2: the regression form E3, the stratified draw, and the cross-fitting correction E3a.
