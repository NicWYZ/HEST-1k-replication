**The gate rule, in the wording Nicolas approved.** Report-and-wait means that no stage after the gated stage starts until the oversight chat has reviewed the report and replied. Not the dependent stages only, and not the expensive ones only. Every stage. Nothing after the gate is set up, staged or piloted. 1. **Where the C3 table is.** The conformal track is complete at tag `round4-conf-final` (`d65626f`), merged into `main` by Nicolas through pull request #5. Q5 reads `results/round4/conformal/C3_real/c3_o_sweep.csv.gz` from `main` at that merge commit, not from the branch, and records the commit it read. The file is gzipped because the plain file exceeds GitHub's size limit; the plain file sits at the same path in the Longleaf project tree with md5 `2c3ceaa42528a1e3ad2979dc1161e542`, and the by-task pooled version `c3_o_sweep_by_task.csv` is beside it.
2. **Columns** are as fixed in the instruction: task, label_set, encoder, method, score, alpha, o, K, fold, draw, coverage, width_mean, width_median, n_test, finite. The HEST tasks are `CCRCC`, `CCRCC_23merged`, `INDIANA_KIDNEY`, `LUNG_XENIUM`; the ACS rows are under task `ACS` with states as groups, one predictor, and $K \le 10$.
3. **Methods** at $o > 0$ are `ghcp` (primary, $\eta = 0$, adaptation on), `within` (the GHCP paper's Std-CP form, which recentres on half the labelled spots and calibrates on the rest, infinite below $o = 25$ at $\alpha = 0.1$), `within_plain` (all $o$ spots calibrate the absolute score, finite from $o = 9$), and `recentred` (the shifted cross-donor quantile, no guarantee). At $o = 0$ they are `pooled`, `hcp` and the one-per-donor interval.
4. **The joint design table** `q5_joint_design.csv` carries, for each task and $m$, regime B's confidence-interval width ratio from Q3 at $m$ labelled spots per donor, and from C3 at $o = m$ the coverage and width of `ghcp`, `within_plain` and `within`, each at $K = 10$ and $\alpha = 0.1$, averaged over encoders and folds, with the finite share beside each. Where the Q3 grid's $m$ and the C3 grid's $o$ do not coincide, use the nearest $o$ at or below $m$ and say so in the column name. Mark which method is the cheapest valid prediction set at each $o$ by the rule the conformal track established: `hcp` at $o = 0$, `ghcp` for $0 < o < 9$, `within_plain` from $o = 9$ up to but not including 25, and `within` from $o = 25$ on, which is narrower there on every task.
5. **The one-paragraph statement** the joint table supports, for the Q5 report's closing page, is that on these data the same few labelled spots per donor serve the confidence interval (regime B, Q3) from the first spot and the prediction set only from about ten spots, so a labelling design of tens of spots on every donor serves both targets, while a design of a few fully labelled donors serves neither as well.
