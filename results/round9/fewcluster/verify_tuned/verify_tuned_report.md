# Independent verification: tuned-PPI finite-population statements T0, T1', T2', T3 and the numbers table

Scope: exact enumeration at G=8 (n=4), G=10 (n=4 for T0/T1', n=5), G=12 (n=5), G=24 (n=8, all 735,471 samples), random f of three kinds (normal, lognormal sigma=1, normal with max moved to mean+4sd). All scripts and `verify_tuned_checks.csv` (185 rows; 178 pass, 6 are "n/a, eps not small", 1 is a known incomplete-list artefact, listed below) accompany this report.

## 0. Conventions and global hypotheses
* Needed throughout: n >= 3 (s^2 = RSS/(n-2) defined), n < G (finite-population factor 1-n/G > 0), f_S non-constant on every sample (Sxx_S > 0; this is also what makes the line (a_S, c_S) of an affine sample unique), f non-constant on the population (follows).
* "theta" = population mean of z. Coverage = P(theta in C) with C closed; intervals with s = 0 are the single point {theta_hat} (convention of the task). Any convention that enlarges the interval at s = 0 only helps T2'; for T1' it is irrelevant (T1' is about all (E2) procedures).
* (E2) must be read as an identity of the map data -> set for each fixed (S, f): C(S, a + c f_S + b x_S, f) = a + c Fbar + b C(S, x_S, f) for all vectors x_S in R^n. T1' uses it with (a, c) = (a_S, c_S) depending on S; this is legitimate only under this reading.

## T0 - proved (with two remarks)
Write z = a + c f + e, with (a, c) the population OLS coefficients and e = e_hat(z) (sum e = 0, sum e f = 0).
1. theta = zbar = a + c Fbar + ebar = a + c Fbar.
2. Sample OLS on (1, f_S) is linear in z_S and reproduces a + c f_S exactly, so theta_hat_S(z) = a + c Fbar + theta_hat_S(e) and the sample residual vector of z equals that of e; hence s_S(z) = s_S(e).
3. Therefore theta in C(S, z_S) iff |theta_hat_S(e)| <= c sqrt((1-n/G) s_S(e)^2 / n): depends on z only through e. Replacing e by b e multiplies both sides by |b|, so coverage is invariant for every b != 0 (not only b > 0; the interval is symmetric).
4. (E2): zbar_S' = a + c fbar_S + b zbar_S, lam' = c + b lam, so theta_hat' = a + c Fbar + b theta_hat; residuals scale by b so the half-width scales by b (b > 0). A point stays a point.
Remarks: (i) e_hat(z) = 0 (z affine in f) gives s = 0 and theta_hat = theta on every sample: coverage 1; T0 is then trivially true. (ii) Needs Sxx_S > 0 and n >= 3.
Numerics: G in {8,(10,4),(10,5),12}, 15 random (f,z) per size, 4 values of c: covered-sample masks of z, e_hat(z), b e_hat(z), a+cf+bz identical on all samples (0 disagreements); E2 endpoint error <= 6e-14; e_hat(a+cf+bz) = b e_hat(z) to 1.4e-14.

## T1' - proved, with corrections to hypotheses/wording
Proof. Fix x in R^G (arbitrary, need not be in K). z_eps = z* + eps x, eps -> 0.
1. e_hat(z_eps) = e_hat(z*) + eps e_hat(x) -> e_hat(z*) != 0 and kappa is continuous at nonzero centred vectors, so kappa(e_hat(z_eps)) < kappa0 for small eps; z_eps in K_OLS(kappa0). STRICT inequality kappa(e_hat(z*)) < kappa0 is genuinely needed (see strictness check below).
2. theta(z_eps) = theta* + eps xbar. For S in W the sample data are z*_S + eps x_S = a_S + c_S f_S + eps x_S, so by (E2) (reading above) C(S, z_eps,S) = a_S + c_S Fbar + eps C(S, x_S, f).
3. theta(z_eps) in C(S, z_eps,S) iff C(S, x_S, f) contains t_S(eps) = d_S/eps + xbar, d_S = theta* - a_S - c_S Fbar != 0.
4. Coverage >= 1-alpha means the missed set has probability <= alpha, so the set A(eps) = {S in W : t_S(eps) in C(S, x_S)} has P(A(eps)) >= P(W) - alpha. The sample space is finite, so along eps_k -> 0 some A is hit infinitely often; for S in A, C(S, x_S, f) contains points with |t_S(eps_k)| -> infinity: unbounded. Hence P_x(C unbounded) >= P(A) >= P(W) - alpha for every x. QED.
Corrections / remarks.
* n >= 3 is NOT used in the proof (only in the tuned procedure's definition). f_S non-constant is used on W (uniqueness of a_S, c_S).
* The conclusion is "unbounded with probability >= P(W) - alpha", not "no valid procedure exists" (procedures that return R with positive probability are not excluded).
* For two-piece z* = 1_{B2}(d_a + d_c f), |B2| = k: P(W) >= pi(k), equality only generically. Samples inside B2^c have line y = 0 (value 0 at Fbar), samples inside B2 have line d_a + d_c f (value d_a + d_c Fbar). The two conditions are theta* = (k/G)(d_a + d_c fbar_B2) != 0 and d_a + d_c Fbar != theta*: two linear forms in (d_a, d_c) that vanish only on two lines of the (d_a,d_c)-plane, so they hold generically but can fail on a given (B2, direction). If d_a + d_c f_g = 0 for some g in B2 additional (mixed) samples become affine and P(W) > pi(k). If one piece fails its condition only the other piece counts (P(W) = C(G-k,n)/C(G,n) or C(k,n)/C(G,n)). Also pi(k) = pi(G-k), and B2 and its complement give the same e_hat up to sign, so k <= G/2 suffices.
* Genericity of "a_S + c_S Fbar != theta" beyond two-piece z*: in every flat of the collinearity lattice with >= 1 affine sample (G=8,n=4: 1037 flats x 3 f kinds; G=10,n=5: 5173 x 3) theta_hat_S is not identically zero on the flat for any affine S (0 exceptions), so the condition holds at a generic point of each flat.
* Strictness: at kappa0 = kappa(z*) exactly (z* the minimiser of kappa in a count-5 flat, G=8, n=4), 0 of 4000 random directions x give kappa(e_hat(z* + 1e-6 x)) <= kappa0: z_eps leaves K, so the argument (which needs it for every x) gives nothing at the boundary.
Numerics (exact enumeration, 15 configurations: G=8 n=4; G=10 n=4,5; G=12 n=5; alpha = 0.05, 0.10; two-piece (B2, phi) found by exhaustive search over all B2 and 181 angles; kappa0 = 1.05 kappa(z*)): enumerated P(W) = pi(k) in all 15 cases; for eps = 1e-6 and every c in {1.96, 10, 100, 1e4}, the max over 8 random x of the tuned coverage is <= 1 - P(W) (15/15 configurations); it equals 1 - P(W) exactly for c = 100 and 1e4 (15/15), for c = 10 in 3/15, and is strictly smaller at c = 1.96 (non-W samples are also missed) (e.g. G=12,n=5,alpha=0.1, c=100: 0.840909 = 1 - 126/792). Coverage falls to 1 - P(W) once eps <~ 1/c (at c=1e4 only eps <= 1e-6 reaches it), as the proof predicts. Also max kappa(e_hat(z_eps)) < kappa0 in every case.

## T2' - proved, with hypotheses made explicit; not tight (no converse as stated)
Proof. By T0 coverage depends on e only through e/||e||, and every e = e_hat(z) with z in K lies in the compact set E = {e : e perp 1, f; ||e|| = 1; max e_g^2 <= kappa0} (closed; contained in K_OLS(kappa0) since e_hat(e) = e). On E the numerator N_S(e) = ebar_S + lam_S(e)(Fbar - fbar_S) is continuous (Sxx_S > 0), hence bounded by some M, and s_S(e) is continuous. Suppose for every c some e_c in E misses with probability > alpha. Take c_j -> infinity, e_j -> e* in E, and (finite sample space) pass to a subsequence with a constant missed set M0, P(M0) > alpha. For S in M0: |N_S(e_j)| > c_j sqrt(kappa_fpc) s_S(e_j) with kappa_fpc = (1-n/G)/n > 0, so s_S(e_j) <= M/(c_j sqrt kappa_fpc) -> 0, hence s_S(e*) = 0, i.e. e*_S is exactly affine in f_S. Thus the fraction of samples on which e* is affine is >= P(M0) > alpha >= beta_OLS(kappa0), contradicting the definition of beta_OLS (e* in K). So some finite c works; c depends on (f, n, kappa0, alpha). QED.
Hypotheses used: n >= 3, n < G (kappa_fpc > 0), Sxx_S > 0, point-interval convention at s = 0 (a larger set only helps), closed class (kappa <= kappa0); beta_OLS is a max of finitely many values so it exists.
Not tight / interplay with T1': T2' is a sufficient condition. For kappa0 strictly above kappa_min of a flat V' with count > alpha*C(G,n), a generic point of V' with kappa <= kappa0 is exactly affine on all its samples with theta_hat_S != 0 (previous check), so the tuned interval misses all of them for every c, and T1' also applies; so generically T1' and T2' meet at the same threshold kappa_dagger = inf{kappa(e_hat(z)) : affine fraction of e_hat(z) > alpha}. They leave a gap only at the boundary kappa0 = kappa_dagger (T1' needs strict <, T2' needs beta <= alpha with the closed class: at kappa0 = kappa_dagger the class contains the minimiser, so T2' fails and T1' is silent) and in degenerate flats with theta_hat_S == 0 (none found).
Numerics. Exact flat lattice (all collinearity subspaces of {e perp 1,f} generated by affine samples, DFS with deduplication; exact kappa_min on each flat by vertex enumeration of {|v_g| <= 1} in the flat) for G=8,n=4 (1038 flats per f) and G=10,n=5 (5174 flats per f), 3 f kinds each; frontier curve kappa*(m) = min kappa over flats with >= m affine samples. For each count level m: "below" test kappa0 = 0.97 kappa*(m), alpha = beta(kappa0) exactly (T2' hypothesis tight): heuristic worst-case search over K (extremal vertices + perturbations v + t u, t in 1e-10..0.5, plus all flats' vertices) finds min coverage >= 1 - alpha in 100% of cases once c >= 30..300 (c on a grid 1.96..1e8); "above" test kappa0 = 1.03 kappa*(m), alpha = (m-1)/C(G,n): min coverage found at c = 1e8 equals 1 - (affine count)/C(G,n) < 1 - alpha in 100% of cases. G=8: 32/32, G=10 n=5: 36/36. G=12 n=5 (flats below single-line flats with >= 7 collinear clusters only, 40,394 flats, normal f only): 15/16; the 1 failure (count 21, "below") is due to the omitted two-line flats (beta underestimated; a count-2 flat exists), not a counterexample. Typical c0 (smallest grid c with worst found coverage >= 1-alpha) is 30-300 (alpha 0.05-0.1 regime); it is larger near the frontier.
Observation (matters for exactness): at the extremal vertex many coordinates tie at the maximum |e_g|; a tie of n coordinates is a constant, hence affine, sample. Exact beta must therefore count these plateau sub-flats (the lattice does; a list of "lines only" does not): e.g. G=12 found 22 affine samples where the line count was 21.

## T3 (a) proved; (b) proved only with corrected hypotheses (the stated sufficient condition is not automatic and is violated exactly in the strong-leverage regime)
(a) e = (I - H) delta_g, H = hat matrix of (1,f). e_j = delta_jg - h_jg; sum e = 0 (e perp 1) so e is already centred; sum e^2 = delta' (I-H) delta = 1 - h_gg (I - H idempotent); max e_j^2 = max{(1-h_gg)^2, max_{j != g} h_gj^2}. Ratio gives the formula. h_gg < 1 because h_gg = 1 would force f_j constant for all j != g, contradicting that every n-subset (n < G, so some subset avoids g) is non-constant. Numerics: max abs error 3.9e-15 over all g, 18 random f per G in {6,8,10,12,15,24,40}.
(b) Tuned-frontier consequence. Spike z* = 1_g: samples avoiding g are exactly affine (z* = 0) with a_S + c_S Fbar = 0 != theta* = 1/G, W = {S not containing g}, P(W) = 1 - n/G = C(G-1,n)/C(G,n); samples containing g are not affine for n >= 3. T1' then gives P(C unbounded) >= 1 - n/G - alpha provided kappa(e_hat(1_g)) < kappa0 strictly. Corrections:
1. Strict inequality (T1' needs kappa < kappa0).
2. "h_gg >= 1 - kappa0 and the max is attained at g" is a correct sufficient condition (then kappa = 1 - h_gg) but the parenthetical is not automatic: because sum_{j != g} h_gj^2 = h_gg(1 - h_gg) (identity, checked to 8.6e-16 on 2640 (f,g) pairs), max_j h_gj^2 >= h_gg(1-h_gg)/(G-1); "max attained at g" forces (1-h)^2 >= that, i.e. h_gg <= 1 - 1/G (0 violations in 2594 attained cases). So for large leverage the condition fails and kappa_spike does NOT equal 1 - h_gg. Counterexample to the unqualified implication "h_gg >= 1 - kappa0 => spike in K_OLS(kappa0)": G=24, one cluster 128 sd out: h_gg = 0.99860 >= 0.9 but kappa_spike = 0.2454 > 0.10 (G=12, 512 sd: h = 0.99996, kappa = 0.314). kappa_spike plateaus at about 0.25 (G=24) / 0.31 (G=12), set by the spread of the other clusters' f. Correct sufficient condition: max{(1-h_gg)^2, max_{j != g} h_gj^2} < kappa0 (1 - h_gg).
3. Table of the outlier scan (G=24): 4 sd: h=0.425, kappa=0.575 = 1-h (attained at g); 8 sd: h=0.739, kappa=0.2614 = 1-h; 16 sd: h=0.918, kappa=0.2145 > 1-h = 0.0821 (not attained at g); 512 sd: kappa=0.247.
4. "Defeats every (E2) procedure with probability about 1 - n/G - alpha": it is the lower bound on P(C unbounded); requires 1 - n/G > alpha to be informative. Confirmed by enumeration (G=10,n=4; G=12,n=5; normal and outlier f, g = argmin spike kappa, kappa0 = 1.02 kappa_spike): tuned coverage at z* + eps x (c = 100, eps = 1e-4, 1e-6) equals n/G exactly (0.4, 0.4, 0.4167, 0.4167).
5. "A tuned frontier can be much stricter than the fixed-coefficient frontier": supported by the attached table (all 24 tuned upper bounds < fixed), but the mechanism is not simply the leverage of the outlier: for a mildly outlying cluster the spike is cheap (kappa_spike = 1 - h_gg), for a very outlying cluster it is not; the quoted comparison with the fixed-coefficient frontier cannot be verified without its definition (I recovered 1/(k*-1) - 1/G with k* = min{k : pi(k) <= alpha} as an exact fit to all 24 rows - a fitted formula, not a derivation).

## Is the tuned frontier a single explicit formula?
No. The fixed-coefficient frontier (as fitted from the table) is 1/(k*-1) - 1/G, a function of (G, n, alpha) only. The tuned frontier is kappa_dagger(f, G, n, alpha) = inf{kappa(e_hat(z)) : fraction of samples on which e_hat(z)_S is affine > alpha}: e_hat = (I-H_f) z depends on f through the hat matrix, kappa(e_hat) is a max-share of that projected vector, and the affine-structure combinatorics (which n-subsets can be collinear in (f_g, e_g)) is also f-dependent. Closed forms exist only in special sub-cases: (i) one-point exceptional sets: kappa_spike(g) = max{(1-h_gg)^2, max_j h_gj^2}/(1-h_gg), explicit in the leverages; (ii) free-u single-line family: kappa_min(B) = 1/max{||v||^2 : v in span((I-H)[:,B]), ||v||_inf <= 1}, a small non-convex problem. Variation across f (G=24, n=8, k=5): 0.0785-0.1008 over 12 normal seeds; the table gives 0.0845 (lognormal), 0.1001 (outlier) versus fixed 0.1583 for all kinds.

## Exact beta_OLS for G up to 24 (sketch)
1. Geometry: e perp (1,f) is affine on S iff the n points (f_g, e_g), g in S, are collinear. Adding an affine function to e changes neither collinearity nor (after projection) kappa, so only the collinearity structure matters. For n >= 3 each affine sample lies on a unique maximal line, lines share <= 1 point, so aff(e) = sum over maximal lines of C(m_l, n).
2. Only configurations with aff > alpha*C(G,n) =: T matter. Enumerate line arrangements (sets of subsets of size >= n, pairwise intersections <= 1, sum C(m,n) > T): for large n this is tiny (G=24, n=8, alpha=0.1: T = 73,547 forces one line of >= 19 clusters and <= 5 free ones; n=6: one line of >= 18). Small n (3-4) needs a DFS with branch-and-bound on sum C(m,n).
3. For an arrangement the realizable e form the linear space V' (dimension d = number of free points, minus gauge) = {e perp 1,f : e|_line affine for each line}; compute by one SVD.
4. kappa_min(V') = 1/max{||v||^2 : v in V', ||v||_inf <= 1}: maximizing a convex function over a polytope, attained at a vertex = d active coordinates; for d <= 6 enumerate C(G,d) 2^d d x d solves in batch (d=5, G=24: 1.4M solves, seconds); for larger d use a global non-convex QP/MIQP solver or a Shor/SDP relaxation for a lower bound on kappa_min (certifies beta <= alpha) with Frank-Wolfe/LP local search for an upper bound (certifies the impossibility side).
5. beta(kappa0) = max count over arrangements with kappa_min <= kappa0, but compute the count AFTER the vertex step: ties of n coordinates at the vertex add constant (affine) samples; handle by also enumerating the sub-flats where extra samples are forced affine (the DFS lattice below the arrangement; verified on G=8,10 where the full lattice is exact).
6. Cost: per f at most C(G,k)-many B for the single-line case (42,504 for G=24,k=5) times an exact d=5 solve; practical via the two-piece 2-D reduction plus shortlist, or a per-B MIQP.
Verified implementation here: full lattice for G=8 (n=4) and G=10 (n=5); partial for G=12 (n=5).
