## Proofs

### (I)
S_h^2=sum_i d_hi^2/(N_h-1), d_hi=e_hi-ebar_h. So V_h = W_h^2(1-f_h) sum_i d_hi^2 /(n_h(N_h-1)) and c_hi = V_h d_hi^2/(V sum_i d_hi^2) = v_h d_hi^2/sum_j d_hj^2. Maximise over i then h. If S_h=0 (in particular take-all, 1-f_h=0) V_h=0 and c_hi=0; kappa_h is 0/0 and must be set to 0 (analyst's convention).

### (II)
Notation: pattern E = in every h in A the sample lies inside one of the two clusters (k_h units / N_h-k_h units). P(E)=prod pi_h(k_h) exactly (independence; the two events inside a stratum are disjoint because n_h>=2).
1. Choice of v. Since sum a_h(k_h) > 1/kappa0, there is v in the open simplex over A with v_h < kappa0 a_h(k_h) for all h in A (a_h=1/kappa2_h). Because the set of such v is open, it can be taken generic (see step 3).
2. Defeating family. Given any population e' (even V=0), split each e'_h (h in A) into J_h (N_h-k_h units) and J'_h (k_h units) arbitrarily. Define e^delta_h = x_h + delta J (cluster 1 at location Delta_h + delta J', cluster 2 at 0 + delta J), Delta_h scaled so that V_h = v_h V; for h not in A put delta e'_h. As delta->0, kappa_h -> kappa2_h(k_h) (jitter changes max-share continuously), non-A strata have v_h=O(delta^2), so kappa_st = max v_h kappa_h -> max v_h kappa2 < kappa0: e^delta is in the class for small delta (this is where strictness is used: jitter raises max-share to first order, so at sum a = 1/kappa0 no slack is left).
3. Equivariance. On a sample s in E the data are D = x(s) + delta J_s (x(s) = collapsed point per stratum). With g: b=1/delta, a_h=-x_h/delta, C(D)=t0(s)+delta C(J_s), t0(s)=sum W_h x_h(s). theta_delta = theta_0+O(delta) with theta_0 != t0(s) provided the 2^|A| numbers sum_h W_h c_h(eps_h) Delta_h are nonzero; each is a nonzero linear form in sqrt(v_h) on a piece of the sphere, so it vanishes only on a nowhere-dense set when |A|>=2 (automatic for |A|=1: c_h in {(N-k)/N, -k/N} != 0). The 'generic' requirement is therefore satisfiable and is part of the proof, not an extra hypothesis. Non-generic populations (t0=theta on some pattern) do exist (script shows the offset), and there the collapsed point covers; the theorem concerns the generic family.
4. Pigeonhole. Along delta_m->0 coverage >= 1-alpha means sum_{s in E} P(s) 1[theta_delta in t0+delta C(J_s)] >= P(E)-alpha. The sample space is finite, so pass to a subsequence with a fixed set Sigma of covered patterns, P(Sigma) >= P(E)-alpha. For s in Sigma, (theta_delta-t0)/delta -> infinity lies in C(J_s) along the subsequence, so C(J_s) is unbounded.
5. Every population. With the partition from step 2 taken from e' itself, the data e'_S equal J_s (up to the group), the sampling measure on patterns is the same uniform measure, hence P_{e'}(C unbounded) >= P(Sigma) >= prod pi_h - alpha. Because J and J' are an arbitrary split of e', this holds for every e' including V=0.
Boundary: at sum a = 1/kappa0 the exact two-point population is in the class (v_h=kappa0 a_h; script: kappa_st=kappa0 to 1e-16) and C is unbounded under it with prob >= pi-alpha, but steps 2/5 fail: the conclusion 'under every population' is false. Concrete counterexample, H=1, N=8, kappa0=1/N: the class is the balanced two-point populations and 'midpoint of the sample range, R on constant data' is equivariant with coverage 1 (script: min coverage 1.000000 over 200 class members), bounded a.s. under any population with no constant sample. So strict '>' in (II) is necessary, and (as in Theorem 1) the H=1 impossibility at kappa0=1/N fails.

### (III)
{SE=0} = {every n_h<N_h stratum sample constant} (W_h>0, 1-f_h>0 on P), so P(SE=0)<=beta_st<=alpha. T-theta and SE are invariant under per-stratum translations and scale together, so we may work on K~ = {e centred per stratum on P, V=1, kappa_st<=kappa0} (take-all coordinates drop out), a compact set (closed condition on a bounded sphere). Suppose for every c some e_c in K~ has F_c(e_c)=P(fail)>alpha. Finitely many samples: pass to a subsequence with e_c->e0 in K~ and a fixed failing set S, P(S)>alpha. For s in S, |T-theta|/SE>c->infinity; if SE_s(e0)>0 the ratio converges to a finite limit, contradiction, so SE_s(e0)=0 for all s in S, i.e. P_{e0}(SE=0)>=P(S)>alpha, contradicting beta_st<=alpha (e0 is in the class). Hence some finite c has sup_e F_c <= alpha. The non-strict '<=' is fine: the exact boundary case beta=alpha is handled because coverage 1-alpha is allowed and only the SE>0 failures need to vanish uniformly. (SE=0 samples with T=theta count as covered, which only helps.)
Degenerate: if P is empty the class is empty (V=0 always).

### (IV)
Population-level reduction: for e in K_st(kappa0) let S = nonconstant strata, p_h = P(constant sample in h), cap_h = 1/kappa_h. P(SE=0)=prod_{S} p_h and v_h kappa_h<=kappa0 with sum v=1, v_h>0 on S is solvable iff sum_S cap_h >= 1/kappa0 (non-strict).
Domination lemma: every nonconstant stratum has (p_h, cap_h) <= (first, second coordinate) of a level. Largest value-group M. (i) M>=N/2: k=N-M<=N/2, Lemma 1 gives cap<=a(k), and by superadditivity of C(.,n) (C(a,n)+C(b,n)<=C(a+b,n)) p <= [C(M,n)+C(k,n)]/C(N,n)=pi(k). (ii) M<N/2: cap<=N (kappa_h>=1/N); p<=max sum C(m_j,n) over partitions with parts<=M, attained by floor(N/M) parts of size M plus remainder (convexity), <=R_h. So if beta_st>alpha some population has prod p>alpha and sum cap>=1/kappa0, so some level choice has product>alpha and sum>=1/kappa0: contrapositive of (IV). Checked exhaustively: 793 (N<=10, n, partition) triples with kappa_min(partition) from multistart SLSQP: 0 violations.
Frontier bounds: (II) gives impossibility when some two-point choice has product>alpha and sum a>1/kappa0, i.e. kappa0>1/Cap_low; (III)+(IV) give possibility when no choice (with R) has sum>=1/kappa0, i.e. kappa0<1/Cap_up. Since Cap_up>=Cap_low the frontier lies in [1/Cap_up,1/Cap_low]; the possible set is a down-set in kappa0.
Additional facts I proved and checked (0 exceptions, N<=40): pi_h(k) is decreasing on k<=N/2 (convex symmetric); R_h <= pi_h(floor(N/2)) (any partition with parts <= N/2 is majorised by (ceil(N/2),floor(N/2))); hence for even N the level (R_h,N_h) is dominated by the two-point level k=N/2 (same capacity N_h, larger pi) and Cap_up=Cap_low; R matters only for odd N (360 (N,n) with N<=40 have a non-dominated R-level, all odd N).

### (V)
(a) For H=1, {k:pi(k)>alpha}={1..k*-1} (pi decreasing), a(k) increasing, so Cap_low=a(k*-1)=1/kappa2(k*-1). If k* exists then R<=pi(floor(N/2))<=pi(k*)<=alpha so the R level is unusable and Cap_up=Cap_low: frontier recovered exactly (2216 (N,n,alpha) cases with N<=40, 0 mismatches). If no k* exists and N is odd, the R-level can be usable and Cap_up=N>Cap_low: only the impossibility endpoint is exact (119 cases, e.g. N=5,n=2,alpha=0.05: [0.2,0.3]). If k*=1 there is no impossibility at all.
(b) Take-all strata: v_h=0, not in P, the sample is deterministic; they enter T and theta identically and never enter SE, beta_st, the levels or the capacity.
(c) G=24,N=2000,m=4,alpha=0.1, equal W, all N even so Cap_up=Cap_low and the frontier is exactly 1/Cap. pi(N/2)=0.12462>alpha; 2^(1-m)=0.125 (the asymptotic form; finite N lowers it, so 'm<log2(2/alpha)' = 4<4.32 is only a heuristic for pi(N/2)>alpha: the exact test is pi(N/2)>alpha). DP over 24 strata (cost grid 2e-4, rounding up/down) brackets Cap in [2112.49, 2113.05]; the optimum is one stratum at k=1000 plus one at k=107 (product pi(1000)pi(107)>0.1, k2=108 would violate), Cap = 2113.048, frontier 1/Cap = 4.7325e-4 (so '4.72e-4' is off by 0.2%, bracket [4.7325e-4,4.7337e-4]). Not 24 strata at k=N/2: pi^2<0.1. Single stratum: class nonempty iff kappa0>=1/N=5e-4, and Theorem 1 needs kappa2(k)<kappa0 strictly; at kappa0=1/N exactly the class is balanced two-point and the midpoint procedure is valid (see (II) boundary), so the statement should read 'for every kappa0>1/N'. Pooled class is nonempty from 1/(GN)=2.08e-5, so the region [2.1e-5, 4.73e-4) is possible and nonvacuous. iid N(0,1) units, G=24, N=2000, m=4, equal W: kappa_st over 20 draws mean 4.11e-4, min 3.04e-4, max 6.67e-4 (the claimed 3.9e-4 is within the spread, but a single draw can lie above 4.73e-4; the 2000-draw distribution run was blocked by a safety check and is not done, see deviations).

### (VI)
Setting: A closed, monotone in kappa (kappa'<=kappa => membership persists). Note kappa_h>=1/N_h whenever V_h>0.
(a) Weak version (proved): if S, k_h, v supported on S with v_h>0 exist such that the exact two-point population (strata outside S constant) has (v, kappa2(k)) in A (equivalently is in K(A)), prod pi_h(k_h)>alpha, then every equivariant procedure with coverage >=1-alpha on K(A) satisfies, under that population, P(C unbounded) >= P(E_t0!=theta) - alpha where E_{t0!=theta} = the collapsed-point patterns with t0 != theta (all of E under genericity). Proof: on E the data are constant in each stratum; the stabiliser of D contains e_h->b e_h+(1-b)x_h, so C(D) is invariant under t->b t+(1-b)t0 for all b>0; hence C(D) is empty, {t0} or contains a ray from t0; covering theta != t0 forces a ray. So the procedure is not a.s. bounded at that population, with no strictness on A needed (closed boundary points are allowed). It says nothing about other populations (equality-case counterexample above).
Strong version (proved): if there is rho>0 such that every (v',kappa') with v' within rho of v and kappa'_h <= kappa2_h(k_h)+rho (h in S), kappa'_h<=1 (h not in S), v'_h<rho (h not in S) lies in A (interior of A at that point), then the proof of (II) steps 2-5 goes through verbatim: every equivariant procedure with coverage >= 1-alpha on K(A) is unbounded with probability >= prod pi - alpha under every population (including V=0), under the genericity of t0 != theta (available since v ranges over an open set). The pooled class gives (II) back: interior <=> v_h kappa2 < kappa0. Remark: only the kappa-direction needs to be interior; v can be tuned exactly by choosing Delta_h(delta), so e.g. in the box class the case 1/v0 integer (v_h=v0 exactly) still works provided kappa2_h(k)(N_h-1)<Lambda0^2 strictly and the S strata take v_h=(1-eps)/m0.
(b) Part 1 (proved): the normalised class K~(A)={centred, V=1, (v,kappa)(e) in A} is compact: boundedness is clear; for closedness take e_m->e0; where V_h(e0)>0 kappa_h is continuous; where V_h(e0)=0 the limit of kappa_h(e_m) is some kappa' in [1/N_h,1] but kappa_h(e0)=0<=kappa', and monotonicity puts (v(e0),kappa(e0)) in A (this is exactly where monotonicity is needed). The proof of (III) then applies unchanged. Part 2 (proved): take e in K(A), S=nonconstant strata (v_h>0), levels from the domination lemma (kappa_h>=kappa2(N-M) or kappa_h>=1/N_h, p_h<=level), monotonicity puts (v, level kappas) in A, strata outside S have kappa=0 and p=1, so P(SE=0)<=product of level first coordinates; sup is a max over finitely many (S,levels) and compact v. For the pooled class this is (IV) exactly.
Box class A={v_h<=v0, kappa_h(N_h-1)<=Lambda0^2}: closed, monotone; kappa_h(N_h-1)=max_i d_i^2/S_h^2 (squared max standardised deviation). kappa2_h(k)(N_h-1)=(N_h-k)(N_h-1)/(N_h k), decreasing in k, so kmin_h(Lambda0)=min{k<=N_h/2: this<=Lambda0^2} and pi_h(kmin) is the best two-point level. Feasible v needs |S|>=m0=ceil(1/v0); every extra stratum multiplies the product by <=1, so the best S has exactly m0 strata and v_h=1/m0<=v0; choose the m0 largest pi_h(kmin_h). R-level admissible iff (N_h-1)/N_h<=Lambda0^2 and is dominated by pi_h(kmin) whenever a two-point level is admissible (R<=pi(floor(N/2))<=pi(kmin)). A two-point level is admissible for all N_h iff Lambda0^2>=(N_h-1)/N_h (even N_h) resp. >=(N_h+1)/N_h (odd N_h), so Lambda0>=2 suffices (precisely: whenever Lambda0^2>=1+1/N_h for every used odd N_h). Then beta(A_box)=prod exactly (not only a bound): the exact two-point population with k=kmin in the m0 chosen strata, v_h=1/m0 is in the class and has P(SE=0)=prod. For smaller Lambda0 with odd N_h and no admissible two-point level, the bound must use the R level (kappa=1/N_h): then it is an upper bound (in all brute-force cases it was attained). If |P|<m0 the class is empty (beta=0 by convention; possibility vacuous). Combining with (a): impossible if prod_top-m0 pi>alpha and strictness kappa2(kmin)(N_h-1)<Lambda0^2 on the used strata (otherwise only the weak version at the exact two-point population).

## Numerical checks (summary; scripts and outputs saved)
1. (I): identity vs definition, 1476 random multi-stratum populations, 0 mismatches (strat_lib smoke test).
2. check_levels_domination.py: all partitions of N=4..10, all 2<=n<N: 793 triples, 0 domination violations; pi monotone in k; R<=pi(floor(N/2)) in every N<=40 case; R-level non-dominated only for odd N.
3. check_II_defeat.py: six configurations (H=2,3; N 5..9; n 2..4; alpha 0.05..0.3). Defeating population from the knapsack argmax at kappa0=1.05/Cap_low. With delta tiny (0..1e-6) coverage of T+-cSE is exactly 1-prod pi (e.g. 0.7333 vs required 0.8; 0.8571 vs 0.9; 0.6 vs 0.7; 0.9286 vs 0.95; 0.8333 vs 0.9; 0.7755 vs 0.8) for c=1e2..1e6 (once c exceeds ~1/delta coverage returns to 1, as it must: the sup is over the class). Equality boundary: exact two-point population has kappa_st=kappa0 (0.138889) and P(SE=0)=0.2667>alpha=0.2 (so IV needs >=). H=1 N=8, kappa0=1/N: midpoint-or-R procedure covers with prob 1 over 200 class members.
4. check_III_adversarial.py: H=2,3 (N 5..8, n 2..3, alpha 0.1..0.3), 12 s random + hill-climb search per setting (about 1e4 to 4e4 class members each). At kappa0=0.99/Cap_up the worst c_needed found was 9.6-13.6 (provisional lower bounds on the sup; at 0.8/Cap_up 2.2-4.0), max P(SE=0) observed <= alpha in every setting; at kappa0=1.05/Cap_low c_needed=inf (diverges, as (II) predicts). Smallest c that worked everywhere in the search: about 14 at 0.99/Cap_up (the true sup is >= these numbers and grows without bound as kappa0 -> 1/Cap_up).
5. check_box_class.py: 40 random designs (H=3..5, N 4..8, n 2..3), v0 in {0.5,0.34,0.3}, Lambda0 in {1.05..3.5}: Lambda0>=2: formula == exact beta (enumerating all multiplicity patterns with kappa_min) in 360/360; Lambda0<2: two-point-only formula strictly below exact in 57/360 (no admissible two-point level), formula+R level == exact in 360/360. The attaining two-point population lies in the box class and has exact P(SE=0) (full enumeration) equal to the formula in 100/100; 6997 random box-class populations never exceeded it.
6. check_V.py: (a) 2216 cases exact agreement; (c) reproduced independently (own big-integer DP): frontier 4.7325e-4; iid kappa_st statistics above.
