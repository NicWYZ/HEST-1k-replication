=== 4. QUANTITATIVE IMAGE-FEATURE PREDICTOR (cross-validated mean per-gene Pearson r ~0.59 on spatial blocks) ===
Compute these 10 features exactly (Python, numpy+PIL), z-score with MEAN/SD below, find 3 nearest centroids (Euclidean in z-space),
predict weighted average of their gene means with weights w=1/(d2+0.3) where d2 = squared distance.
(A random forest on the same features reached r~0.62; linear ridge only 0.48 -> relationship is nonlinear: use the centroids or templates.)
Per-gene CV r with this approach was best for VIM 0.9, POSTN 0.9, TYRP1 0.85, MGP 0.85, LYZ 0.77, HAPLN1 0.74, BIRC3 0.7, epidermal genes ~0.6-0.7;
weakest (~0.4) for CCL19, CCL22, CD1B, HBD, IL1B, SELE, TFF3, MMRN1 (predict near their mean ~0.5-0.8, modulated slightly by immune/stroma content).

import numpy as np; from PIL import Image
HE=np.array([[0.65,0.70,0.29],[0.07,0.99,0.11],[0.27,0.57,0.78]]); HE/=np.linalg.norm(HE,axis=1,keepdims=True); Mi=np.linalg.inv(HE)
def feats(path):
  a=np.asarray(Image.open(path).convert('RGB')).astype(float); r,g,b=a[...,0],a[...,1],a[...,2]
  c=(-np.log((a+1)/256.).reshape(-1,3))@Mi; h=c[:,0]; e=c[:,1]
  gray=a.mean(-1); sat=a.max(-1)-a.min(-1)
  white=(gray>215)&(sat<25); tissue=~white
  nuc=(h.reshape(224,224)>0.6)
  pink=tissue&(r-b>20)&(g<170)&~nuc
  grad=(np.abs(np.diff(gray,axis=1)).mean()+np.abs(np.diff(gray,axis=0)).mean())/2
  return dict(white=white.mean(),H=h.mean(),E=e.mean(),nuc=nuc.mean(),pink=pink.mean(),grad=grad,
     rb=(r-b)[tissue].mean() if tissue.any() else 0, sat=sat[tissue].mean() if tissue.any() else 0,
     dark=(gray<120).mean(), gstd=gray.std())
Feature meaning: white=glass fraction; H/E=mean hematoxylin/eosin optical density; nuc=fraction strongly hematoxylin pixels (nuclei);
pink=eosin-dominant non-nuclear tissue fraction (keratinocyte cytoplasm, keratin, collagen); grad=fine texture (high in cellular nests);
rb=mean(R-B) over tissue (positive=pink/red tissue, negative=purple/blue); sat=saturation; dark=very dark pixels; gstd=gray std.
